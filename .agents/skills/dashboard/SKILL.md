# /dashboard - Seen Jobs Interactive Web Dashboard

Launches or verifies the live interactive web dashboard for `job_scraper/seen_jobs.json`.

## Usage

Start the dashboard server:
```bash
python3 tools/seen_jobs_dashboard.py
```

Open in browser:
- [http://127.0.0.1:8765](http://127.0.0.1:8765)
