# /dashboard - Seen Jobs Interactive Web Dashboard

Launch or access the interactive web dashboard for `job_scraper/seen_jobs.json`.

## Instructions

1. Check if the dashboard server is running at `http://127.0.0.1:8765/api/status`.
2. If not running, start it using:
   ```bash
   python3 tools/seen_jobs_dashboard.py
   ```
3. Return the clickable link to the user: [http://127.0.0.1:8765](http://127.0.0.1:8765).
